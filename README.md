## GitHub and Pull Requests

Go to the [2026_Data Management glossary](https://github.com/DATA3101-2026/Assignment-Practice)
and complete the following steps:

- [Fork repository](https://docs.github.com/en/pull-requests/reference/forks) from GitHub to your computer
  
- [Create a new branch with git](https://education.github.com/git-cheat-sheet-education.pdf)

- In the Quarto document, add your definition to an existing word or name, or add in a new data term or organization you are interested in for your final project
  
- Push your edits to the remote repository
- On GitHub, create a [pull request](https://docs.github.com/en/pull-requests/reference/pull-requests) with notes on what you have changed
